Ten SQL queries, one business question each

These are the query files behind the gold vs Malaysian household indicators case study. Each file is plain SQL, runs in DuckDB against the datasets described in the README, and opens with a comment naming the business question and the SQL concept it practises. The sourcing for every input file is in the provenance table.

  • q01_inflation_trend.sql
    How fast have Malaysian consumer prices risen since 2021?
    date_trunc, aggregation, LAG window function for year-on-year change
  • q02_gold_price_myr.sql
    What did a gram of gold actually cost in ringgit each month?
    joining two daily sources onto a monthly grain, troy ounce to gram conversion, CASE flags for data completeness
  • q03_gold_vs_inflation.sql
    Did gold in ringgit beat Malaysian inflation, month by month?
    LEFT JOIN across three grains, computed columns, excluding the first 12 months needed for year-on-year
  • q04_window_analysis.sql
    Is the recent gold move a spike or a sustained trend?
    12-month moving average, cumulative product return, ROWS BETWEEN frame, MAX and MIN OVER
  • q05_rank_periods.sql
    Which years and months were genuinely the best for a ringgit gold buyer?
    CTE, GROUP BY plus RANK() OVER, two answer shapes in one file
  • q06_affordability_state.sql
    How affordable is a gram of gold for a median household in each state?
    joining an annual survey grain to a monthly price grain, ranking across states, percentage calculation
  • q07_retail_and_labour.sql
    Does gold strength line up with retail spending and the labour market?
    multi-table join, conditional aggregation, deriving a yearly series from monthly data, NULL-safe comparison
  • q08_validation.sql
    Can the numbers be trusted before publishing?
    data-quality checks: coverage, gaps, cross-source agreement between the ECB rate and Bank Negara spot rate
  • q09_usd_decomposition.sql
    Is the ringgit doing the work, or is the metal?
    decomposition of the ringgit return into a dollar return and a currency effect
  • q10_fx_subperiods.sql
    Did the currency effect persist, or was it a phase?
    named sub-periods measured start to end on monthly averages, plus a constant-exchange-rate counterfactual

Served as raw text rather than rendered, so the queries can be read and copied exactly as they were run.
