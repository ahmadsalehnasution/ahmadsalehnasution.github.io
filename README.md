# ahmadsalehnasution.github.io

Personal site for Ahmad Saleh. Plain HTML, CSS and a small JavaScript file. No build step.

- index.html: all content
- dashboard-fifa.html: embedded Power BI reports for the FIFA project
- assets/style.css: layout, colours (light and dark), responsive rules
- assets/main.js: scroll reveal and active nav link (the page works without it)
- assets/favicon.png

To deploy on GitHub Pages, replace the contents of the repository with this folder and push.
